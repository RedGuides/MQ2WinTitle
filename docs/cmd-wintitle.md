# /wintitle

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/wintitle reload
/wintitle fixtitle [state]
/wintitle debug [off|on]
/wintitle petdebug [off|on]
/wintitle [help]
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
Change your EQ window titlebar (caption) text, to display data of your choice.
<!--cmd-desc-end-->

## Options

`reload`
:   Reload configuration from ini file

`fixtitle [state]`
:   Call function to 'fix' title based on game state

`debug [off|on]`
:   Toggle displaying debugging messages to chat, or force on/off

`petdebug [off|on]`
:   Toggle displaying pet debugging messages to chat, or force on/off

`[help]`
:   This help
